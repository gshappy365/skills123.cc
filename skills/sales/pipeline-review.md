# Pipeline Review — Sales Plugin

> 所属插件：[Sales](/plugins/sales) · 来源：Anthropic knowledge-work-plugins · 兼容：Cowork + Claude Code

---

## 概述

Pipeline Review 是 Sales 插件的核心命令之一。它将管道审查从"凭感觉判断"升级为**数据驱动的管道健康度评估**——分析每个商机的状态、风险、优先级，生成结构化的周度行动方案。与 CRM 自带的报表不同，这个技能理解销售流程的动态性：它知道一个停滞 30 天的商机比一个刚创建的商机更危险，也知道单线程商机意味着什么。

## 核心能力

### 1. 管道健康评分

四维评分体系，每项 25 分，总分 100：

| 维度 | 权重 | 评估内容 |
|---|---|---|
| **阶段推进** | 25 分 | 商机是否在正常推进？停滞 30+ 天的扣分 |
| **活动时效** | 25 分 | 最近一次联系距今多久？14+ 天无活动的扣分 |
| **关闭日期准确性** | 25 分 | 关闭日期是否真实？过期未更新的扣分 |
| **联系人覆盖** | 25 分 | 是否有多位联系人？单线程商机扣分 |

### 2. 商机优先级矩阵

基于五因子加权模型排序：

| 因子 | 权重 | 评估标准 |
|---|---|---|
| **关闭日期** | 30% | 越近的越优先 |
| **商机规模** | 25% | 越大的越优先 |
| **销售阶段** | 20% | 越后期的越优先 |
| **活动活跃度** | 15% | 越活跃的越优先 |
| **风险等级** | 10% | 越低风险的越优先 |

可自定义权重："本周我重点关注大单，帮我按规模优先排序。"

### 3. 风险识别

自动标记四类风险商机：

| 风险类型 | 判定标准 | 建议操作 |
|---|---|---|
| **停滞商机** | 同一阶段超过 30 天 | 推进或降级 |
| **沉默商机** | 14+ 天无活动 | 重新接触或标记 |
| **过期关闭日期** | 关闭日期已过 | 更新日期或推至下季度 |
| **单线程商机** | 仅一位联系人 | 拓展更多干系人 |

### 4. 管道卫生审计

| 问题 | 影响 | 处理方式 |
|---|---|---|
| 缺少关闭日期 | 无法预测 | 添加合理关闭日期 |
| 缺少金额 | 无法估值 | 估算或确认 |
| 缺少下一步 | 无行动方向 | 定义下一步 |
| 缺少主要联系人 | 无法跟进 | 分配联系人 |

## 输出格式

每次审查生成结构化 Markdown 报告：

```markdown
# Pipeline Review: [日期]

**数据来源**: [CSV / 手动输入 / CRM]
**分析商机数**: [X]
**管道总价值**: $[X]

## 管道健康评分: [X/100]

## 本周优先行动
1. [最高优先级商机] — $[X] — [原因] — [具体行动]
2. [第二优先级] — $[X] — [原因] — [具体行动]

## 风险标记
- 停滞商机: [X] 个 — [列表]
- 沉默商机: [X] 个 — [列表]
- 过期关闭日期: [X] 个 — [列表]
- 单线程商机: [X] 个 — [列表]

## 管道结构
- 按阶段分布: [各阶段商机数和金额]
- 按关闭月份分布: [各月商机数和金额]
- 按规模分布: [$100K+ / $50K-100K / $25K-50K / <$25K]

## 建议移除的商机
- [60+ 天无活动的商机]
- [多次推迟无进展的商机]
```

## 使用场景与案例

### 场景 1：每周管道审查

**输入**：
```
/pipeline-review
```

**输出**：完整的管道健康报告，包含评分、风险标记、优先级排序和行动方案。

**关键价值**：从手动翻 CRM 的 30 分钟压缩到一句话命令，且输出结构一致，便于周与周之间对比。

### 场景 2：特定销售代表的管道

**输入**：
```
/pipeline-review 张三
```

**输出**：聚焦张三的管道，分析其商机健康度、风险分布和本周行动建议。

**关键价值**：销售经理可以快速了解每个团队成员的状态，无需逐一查看 CRM。

### 场景 3：输入方式灵活

**输入**：
```
我有 12 个商机。两个大的在谈判阶段，我有信心。三个在发现阶段卡了一个多月。其余的在中段，但有些好久没联系了。
```

**输出**：即使没有 CRM 导出，AI 也能基于描述性输入生成结构化分析和建议。

**关键价值**：零配置即可使用，适合快速场景或数据不可用的情况。

## 与其他工具对比

| 维度 | Pipeline Review（本技能） | Salesforce 报表 | Excel 手动分析 | 销售会议讨论 |
|---|---|---|---|---|
| 数据输入 | CSV/描述/自动拉取 | 需在 CRM 中维护 | 需手动录入 | 口头描述 |
| 风险识别 | 自动标记 4 类风险 | 需自定义规则 | 手动标记 | 凭记忆 |
| 输出一致性 | 每次结构相同 | 取决于报表设计 | 取决于模板 | 每次不同 |
| 学习成本 | 一句话触发 | 需学习报表工具 | 低 | 无 |
| 分析深度 | 多维度加权 | 取决于配置 | 取决于能力 | 经验驱动 |

## 最佳实践

1. **每周固定审查** — 管道健康度衰减很快，建议每周一次，及时发现问题
2. **果断清理死商机** — 停滞的商机会虚增管道、扭曲预测，果断标记为 lost
3. **每笔商机多线程** — 一个人失联就丢单，确保每笔商机有 2+ 联系人
4. **关闭日期要真实** — 关闭日期是你预期签字的日期，不是"希望"的日期
