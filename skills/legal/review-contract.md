# Review Contract — Legal Plugin

> 所属插件：[Legal](/plugins/legal) · 来源：Anthropic knowledge-work-plugins · 兼容：Cowork + Claude Code

---

## 概述

Review Contract 是 Legal 插件中最核心的技能。它将合同审查从"逐条阅读"升级为**基于组织谈判手册的结构化条款分析**——逐条对比、标记偏差、生成修改建议、提供商业影响分析。与传统的人工审查不同，这个技能能自动加载你组织的标准立场，在几分钟内完成对一份合同的全面审查，并输出结构化的红线和谈判策略。

## 核心能力

### 1. 八步审查流程

```
Step 1: 接收合同（文件/URL/粘贴文本）
Step 2: 收集上下文（你方角色、截止日期、关注点）
Step 3: 加载谈判手册（标准立场 + 可接受范围）
Step 4: 逐条分析（对照手册逐条审查）
Step 5: 偏差标记（GREEN/YELLOW/RED 三档）
Step 6: 生成红线（具体修改措辞）
Step 7: 商业影响分析（每个偏差的业务含义）
Step 8: 路由（连接 CLM 则自动归档）
```

### 2. 三档偏差标记系统

| 等级 | 含义 | 行动 |
|---|---|---|
| **GREEN** | 符合或优于标准立场 | 注意即可，无需谈判 |
| **YELLOW** | 超出标准但在可接受范围内 | 生成红线 + 回退方案 |
| **RED** | 超出可接受范围或构成重大风险 | 解释风险 + 提供市场标准替代方案 + 建议升级路径 |

### 3. 覆盖的主要条款类型

| 条款类别 | 审查要点 |
|---|---|
| **赔偿** | 赔偿范围、上限、触发条件 |
| **责任限制** | 除外事项、金额上限、间接损失 |
| **知识产权** | 所有权归属、许可范围、背景 IP |
| **保密** | 保密期限、例外情况、违约救济 |
| **终止** | 终止条件、通知期、终止后义务 |
| **数据保护** | 数据处理条款、DPA 要求、跨境传输 |
| **费用与支付** | 定价、付款条件、滞纳金、审计权 |
| **管辖与争议解决** | 管辖法、仲裁/诉讼、地点 |

## 输出格式

```markdown
# 合同审查报告

## 执行摘要
[合同类型、审查范围、整体风险评估]

## 关键发现

### 🔴 RED — 需要升级
| 条款 | 位置 | 问题 | 风险 | 建议 |
|---|---|---|---|---|
| [条款] | [段落] | [偏差描述] | [风险说明] | [修改建议] |

### 🟡 YELLOW — 需要协商
| 条款 | 位置 | 问题 | 建议 | 回退方案 |
|---|---|---|---|---|
| [条款] | [段落] | [偏差描述] | [修改建议] | [备选方案] |

### 🟢 GREEN — 符合标准
[列举已确认的条款]

## 谈判策略
1. **必须争取** — [RED 条款，不可让步]
2. **重点协商** — [YELLOW 条款，优先谈判]
3. **可以接受** — [GREEN 条款，无需讨论]

## 建议下一步
[具体行动项和时间线]
```

## 使用场景与案例

### 场景 1：供应商合同审查

**输入**：
```
/review-contract vendor-agreement.pdf
我方是采购方，截止日期下周五，重点关注数据保护和责任限制。
```

**输出**：逐条分析报告，标记 RED/YELLOW/GREEN 条款，包含红线修改建议和谈判优先级。

**关键价值**：从数小时的人工审查压缩到几分钟，且输出结构一致，便于法务团队 review。

### 场景 2：NDA 快速分类

**输入**：
```
帮我看看这份 NDA 有没有问题。
```

**输出**：快速评估 NDA 类型（单方/双方）、关键条款审查、风险标记。

**关键价值**：低风险的 NDA 可以快速通过，法务资源集中在复杂合同上。

## 最佳实践

1. **配置谈判手册** — 创建一个 `legal.local.md` 文件定义你组织的标准立场、可接受范围和升级触发条件，这是从 Standalone 到 Supercharged 的关键一步
2. **提供业务上下文** — "这笔交易价值 $500K，战略重要性高"会影响 AI 的风险判断
3. **指定关注重点** — "数据保护是关键"让 AI 在该维度投入更多分析深度
4. **AI 辅助，人工决策** — AI 审查作为第一道防线，最终决策由法律专业人士做出
