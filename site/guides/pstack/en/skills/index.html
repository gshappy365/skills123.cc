Skills at a glance

34 skills, plus 24 principles. You don't need to memorize them. Day to day, type /pstack:poteto-mode and it calls the “Auto” ones itself. Come here to call one by name, or to look up a name the AI mentioned. Click a card to see how it differs from just asking, what its document says, and the full text.

Start here: meet these three

  • /pstack:poteto-modeType it yourselfThe main entry point. You say what you want and what counts as done; it plans the steps itself.When to useAnything that needs care. Skip it for an obvious one-line change.
  • /pstack:poteto-helpType it yourselfAsk it "which skill fits this?" and it answers with a prompt you can send as is.When to useYou're just starting, or you're not sure which skill to use.
  • /pstack:setup-pstackCall when neededPicks your models: it checks what you can use, asks your budget, and writes one config all skills share.When to useRun it right after installing. Run it again to switch models or save money.

Understand you first

  • /pstack:in-your-own-wordsType it yourselfHas the AI say back what you want in its own words, so you catch misunderstandings early.When to useYour request is messy or a long discussion, and you worry the AI will get it wrong.
  • /pstack:sharpenType it yourselfTightens your prompt: adds the steps and checks an expert would think of. It doesn't do the work.When to useAn important job, and you want the request right before you send it.

Understand the code

  • /pstack:howAutoExplains how a piece of code runs today: the flow, the key types, the easy-to-miss traps.When to useYou want to understand it before changing it, or you suspect it's slow.
  • /pstack:whyAutoFinds out "why it was done this way" from Git history and docs, with a source for every claim.When to useYou see odd code or config and want its story, and whether the reason still holds.
  • /pstack:teachCall when neededCombines /pstack:how and /pstack:why into one explanation that builds up, diagram by diagram, until you get it.When to useA summary isn't enough and you want to really understand a change or a module.
  • /pstack:recallCall when neededReads your recent chats and shared records to remind you where things stand and what's next.When to useYou're back on an old topic after a few days, or want your progress back before a new chat.

Design and review

  • /pstack:architectAutoBefore code that spans modules, it settles how it's called and what the types are, then compares options.When to useThe change reaches past one function and touches several modules.
  • /pstack:arenaAutoSeveral AIs each try the problem, another company's model scores them, and the best one absorbs the others' good ideas.When to useChoices that are hard to change later, like names, formats or algorithms, where you want options.
  • /pstack:swarmAutoSplits the work into separate pieces, sends one AI per piece, and sums it up in one report.When to useYou need to go through a lot: every package, every feature.
  • /pstack:interrogateAutoHas several different models hunt for bugs in your change, keeping only ones a command can show. It changes nothing.When to useThe code is written but you're not confident, and want it picked apart before merging.
  • /pstack:blast-radiusCall when neededWhat else could a small change break? It finds out, and runs code to prove why it's safe.When to useThe change is small but you're not fully at ease with it.
  • /pstack:figure-it-outAutoWhen none of the 23 ready-made approaches fit, it designs one on the spot. You can check every step.When to useBig jobs, jobs with no ready-made approach, or jobs you'll review when you're back.

Build and clean up

  • /pstack:tddCall when neededWrites a failing test first, then fixes the code, then runs the test again to see it pass.When to useFixing a bug, when tests are easy to run on your machine.
  • /pstack:typescript-best-practicesCall when neededTurns the type principles into concrete TypeScript habits, like handling every possible case.When to useThe task touches .ts / .tsx files. It doesn't load on its own; you have to name it.
  • /pstack:unslopAutoTakes the "AI flavor" out of writing: stock phrases, empty words, lists of three, em dashes.When to useREADMEs, PR descriptions, commit messages, or an AI reply that's too wordy.
  • /pstack:no-commentsAutoCleans up comments before review, keeping only licenses, public API docs and notes on outside rules.When to useBefore the code goes to review.
  • /pstack:technical-writingAutoWrites docs to a clear standard, editing line by line until a tired engineer gets it in one read.When to useWriting docs, RFCs, READMEs, PR descriptions or commit messages.

Verify

  • /pstack:create-verification-skillCall when neededMakes a "verification skill" for your project that teaches the AI to really use each feature like a user.When to useYou have no automatic way to prove a feature really works. The most useful thing a beginner can do.
  • /pstack:maintain-verification-skillCall when neededAfter the app changes, it checks the verification skill feature by feature and fixes what's stale. It never touches product code.When to useBest run once a day. You can make it a scheduled task.
  • /pstack:create-formal-verification-skillCall when neededFor cases tests can't reach (like concurrency or retries), it checks that a rule holds every time.When to usePlaces where a mistake is costly and tests can hardly trigger it.
  • /pstack:maintain-formal-verification-skillCall when neededWhen verified code changes, it updates and reruns the check. It tells you: stale check, or real bug.When to useA merge or refactor touched verified code.
  • /pstack:statechartCall when neededDraws the states a user goes through, and marks the ones that break a rule and how you get there.When to usePeople who don't read code, like product and design, need to "see" how it behaves.
  • /pstack:benchmark-checklistAutoChecks a performance number against 7 questions. The verdict is only faster, slower, no difference, or not sure.When to useYou measured performance, or someone's numbers look suspiciously good.

Report, review, get smoother over time

  • /pstack:broCall when neededSays the last reply again in plain words: shorter, no jargon.When to useThe AI's reply was very technical and you still don't know what it said.
  • /pstack:ketchupCall when neededSounds like "catch up": what changed, and which decisions are waiting on you. It only reads, never changes anything.When to useYou stepped away and want a quick update.
  • /pstack:ketchup-videoCall when neededSame as /pstack:ketchup, but as a short slideshow video with captions.When to useYou'd rather watch the progress than read it.
  • /pstack:show-me-your-workAutoHas the AI log one line per decision: what it did, why, the evidence, the result.When to useLong tasks, or tasks you'll leave running on their own.
  • /pstack:reflectCall when neededAfter a task, three reviewers read the chat and suggest improvements. Nothing changes until you approve.When to useA task was too slow or went the long way round, and you want to avoid that next time.
  • /pstack:correctCall when neededFinds mistakes the AI keeps repeating and blocks them, with structure and types first and docs last.When to useYou're correcting the same mistake for the second time.
  • /pstack:poteto-mode well and want one that's more like you. /pstack:automate-me turns a preference you stated once into a rule. codifies only habits seen across several slices of your history. dumps 20 questions on you at once. asks one or two multiple-choice questions with 4 to 6 options, then one open question. fills the skill with vague sections like "communicate clearly". adds a section only where you have a specific rule, and skips the rest.">/pstack:automate-meCall when neededReads your chats and builds a "<your-name>-mode" skill that works the way you do.When to useYou know /pstack:poteto-mode well and want one that's more like you.

Other

  • /pstack:make-bot-uiCall when neededBuilds a small web page whose buttons wake Grok Bot. Keys stay on your computer.When to useYou use Grok Bot and want a button-style control panel. Most people won't need it.
