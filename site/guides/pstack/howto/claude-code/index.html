在 Claude Code 里用

一句话两条命令装好，命令前加 pstack:，按「均衡」方案配模型，再开一个新会话。

装好 5 分钟，读完 10 分钟适用：平时用 Claude Code，想在里面用 pstack完整教程第 1 步：安装 pstack

技能不会自己跳出来

除了 setup-pstack，每个技能都要你亲手打出来才运行。你说「帮我修个 bug」，它不会自己启用 /pstack:poteto-mode。

选模型，然后开新会话

装完先跑一次：

它会问你推理预算（让模型想多久），再给每个模型角色配一个模型。最后写出一个文件：~/.claude/rules/pstack-models.md。

Claude Code 每次开新会话，都会读这个文件夹里的 .md 文件。所以跑完 setup，退出重开一个会话再干活。当前会话用的还是旧设置。

模型写成「名字 + 档位」，比如 opus xhigh。名字只有 opus、sonnet、haiku、fable。这些行放在这一个文件里就行，不要抄进 CLAUDE.md。

怎么配最好

大多数人选「均衡」就行：会话用 opus，写代码交给 sonnet。

为什么？两样东西决定用什么模型：

  • 会话模型：你用 /model 选的那个，就是你直接对话的 AI。它负责挑做法、派活、审每一份改动。
  • 设置文件里的每一行：派出去干活的帮手 AI（子代理）各用什么模型。

pstack 默认让 grok 写代码。Claude Code 里用不了 grok，这些行就变成 inherit-parent，意思是跟着会话模型走。

所以什么都不改、会话又用 opus，所有活都是 opus 干的：花费最高，评审的两个座位也是同一个模型。均衡方案把写代码换成 sonnet，价钱减半，评审也有了两个模型。

价钱是 2026 年 10 月的 API 标价，每百万 token。用订阅的话，贵的型号额度用得快：

型号 输入 / 输出 适合
fable $10 / $50 最强，不计成本时用
opus $4 / $20 会话、做判断、最难的改动
sonnet $2 / $10 写代码、评审的第二个座位
haiku $0.1 / $0.5 不建议用

haiku 不建议用：检查结果也用写代码那一行的模型，换成最便宜的，检查也会变弱。

三套方案

会话用 opus，设置文件里的 inherit-parent 全换成 sonnet xhigh。

会话要读懂你、审改动，给 opus。写代码的帮手拿到的是说清楚了的活，sonnet 做得了。最难的改动走 hardest tasks，还是 opus。

~/.claude/rules/pstack-models.md（均衡）
# pstack model configuration. One line per role. Delete a line to fall back to the skill default.
# budget: large (xhigh)
feature, refactoring: sonnet xhigh
bug-fix: sonnet xhigh
perf-issue: sonnet xhigh
hillclimb: sonnet xhigh
judgment and prose: opus xhigh
hardest tasks: opus xhigh
how explorer: sonnet xhigh
how explainer: opus xhigh
why investigators: sonnet xhigh
why synthesizer: opus xhigh
reflect tooling: sonnet xhigh
reflect judgment, divergent, synthesizer: opus xhigh
arena runners: opus xhigh, sonnet xhigh
arena cross-judge pool: opus xhigh, sonnet xhigh
swarm workers: sonnet xhigh
architect runners: opus xhigh, sonnet xhigh
interrogate reviewers: opus xhigh, sonnet xhigh

会话用 sonnet，设置文件用默认的，预算选 medium。

一行都不用改：inherit-parent 跟着会话变成 sonnet，做判断的还是 opus。medium 把档位从 xhigh 降到 high。复杂的活先用 /model 换回 opus 再开始。

fable 放在最要判断的地方：讲解、汇总、最难的改动。评审组列了三个模型，就派三个帮手。fable 的标价是 opus 的 2.5 倍。账号用不了 fable 的，setup 里选不到它。

三套都不用 unlimited 预算。最难的那一步，pstack 自己会临时升一档。

怎么写进去

  1. 用 /model 选好会话模型。
  2. 跑 /pstack:setup-pstack，预算按方案选。
  3. 它问要不要改角色时，把上面的文件贴给它，让它照着写。
  4. 退出，开一个新会话。

看到 Skipped in Claude Code

Cursor 的定时任务、Bugbot 审查机器人、云端代理，Claude Code 都没有。用到它们的步骤会被跳过，回复里留一行，然后接着做：

你会看到这样一行
Skipped in Claude Code: <哪一步>. <为什么跳过>.

开 PR 不受影响，它会改用 gh pr create。/loop 这里也有。如果它说留了占位符（比如缺一个链接），看一眼缺什么，需要就自己补上。

打开自动更新

Claude Code 默认不更新第三方插件。打开自动更新：

  1. 在对话框输入 /plugin。
  2. 打开 marketplaces 标签页。
  3. 选中 cursor-plugins。
  4. 选 enable auto-update。

想手动更新，在终端里运行：

更新后默认模型变了，旧的设置文件还会用旧模型。处理办法看更新、查看、卸载。

卸载或者暂停

在对话框里输入：

再输入 /reload-plugins，或者重开 Claude Code。只想暂停一阵，把 uninstall 换成 disable，要用时换成 enable。跑过 setup 的，卸完把 ~/.claude/rules/pstack-models.md 也删掉，不然每个新会话还会读它。

卡住了？

打了命令没反应，菜单里也找不到。

插件市场装的，要打 /pstack:poteto-mode，不带 pstack: 它不认。先输入 /pstack:，菜单会只列出 pstack 的命令。

跑完 setup，换的模型没生效。

设置文件只在新会话开始时读。退出重开一个会话。还不行，就打开 ~/.claude/rules/pstack-models.md，看那一行是不是你选的模型。

回复说 /pstack:arena 跳过了评委，或者没找到别家的审阅者。

有几步要求「另一家」的模型来审，比如 /pstack:arena 的评委。Claude 的模型都算同一家，所以它会跳过评委、自己挑，并说一声。arena cross-judge pool 那一行在这里基本用不上。想要别家的眼光，把要紧的评审拿到 Codex 或 Cursor 里再跑一次 /pstack:interrogate。

技能里写的是 Cursor 的叫法，要我自己换吗？

不用，插件里带了对照说明（docs/harness/claude-code.md），AI 自己换算。比如 .cursor/rules/ 改读 CLAUDE.md（没有就读 AGENTS.md），云端代理改成本地的 worktree。

AI 说 Skill 工具调不动 pstack 的技能，坏了吗？

没坏。在 Claude Code 里，大部分 pstack 技能本来就调不动。AI 会直接读那个技能的 SKILL.md 照着做。你照常打命令就行。

放它跑了一晚上，早上发现停在权限确认上。

放手之前，先放行常用命令：git、gh、测试和构建命令。Claude Code 自带的 /fewer-permission-prompts 会找出你常用的只看不改的命令，写进项目的 .claude/settings.json。会改东西的命令，放不放你自己定。
