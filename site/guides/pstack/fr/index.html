Avant que l'IA dise « c'est fait », faites-la essayer elle-même

pstack est un ensemble gratuit et open source de règles de travail que vous installez dans votre IA. Avec lui, l'IA vérifie d'abord qu'elle a bien compris ce que vous voulez, puis ne change que ce qui doit changer. Pas besoin de savoir coder.

Vous débutez ? Commencez iciJe code : le guide complet (en anglais)

Le parcours débutant : trois leçons, 20 minutes.

Ça vous est déjà arrivé ?

  • L'IA dit « c'est fait ! ». Vous ouvrez, et le bouton ne fait rien.
  • Vous dites « ça ne marche toujours pas ». Elle répond « désolée, c'est corrigé ». Même résultat, encore et encore.
  • Vous vouliez un petit changement, et elle a modifié plein de choses que vous n'aviez pas demandées.

Trois leçons suffisent pour débuter

Lisez-les dans l'ordre, 20 minutes en tout. Après ces trois leçons, vous savez vous en servir. Le reste du site, vous le consulterez plus tard, au besoin.

  1. 1Ce qu'il fait pour vous3 minutes · Ce qu'est pstack, ce qu'il vous faut, ce que ça coûte
  2. 2L'installer5 minutes · Tapez deux lignes dans Claude Code et choisissez une option
  3. 3Première utilisation10 minutes · Créez une petite page web avec un seul message en trois parties

C'est pour vous ?

Oui, si

  • Vous avez déjà créé de petites pages, extensions ou outils avec l'IA, et vous vous êtes déjà fait avoir par un « c'est fait » qui ne l'était pas
  • Vous avez déjà Claude Code (ou Cursor, ou Codex) et vous savez y discuter avec l'IA
  • Vous préférez que ce soit juste plutôt que rapide

Pas encore, si

  • Vous n'avez jamais utilisé un outil comme Claude Code : installez-le d'abord avec le guide officiel, et revenez quand vous savez discuter avec l'IA
  • C'est un tout petit changement, comme une faute de frappe ou une couleur : demandez-le directement à l'IA
  • Vous voulez seulement le plus rapide et le moins cher : pstack vérifie davantage, donc c'est plus lent et ça consomme davantage votre forfait

Si vous codez

pstack, c'est le pack de skills que poteto (membre de l'équipe React, chez Cursor) utilise tous les jours pour son propre code : 34 skills, 23 playbooks et 24 principes d'ingénierie. Ci-dessous, les quatre étapes qu'il suit pour chaque tâche, et le guide complet en 9 étapes.

Pour l'instant, le guide complet existe en anglais (et en chinois).

Vous dites une phrase

L'objectif, et comment vous saurez que c'est fini. Par exemple : « reproduis d'abord le bug, puis corrige, puis vérifie ».

choisir

/pstack:poteto-mode choisit un playbook

Il choisit l'un des 23 playbooks et recopie ses étapes telles quelles dans la liste de tâches.

faire

Les skills s'enchaînent

/pstack:how pour lire le code, /pstack:architect pour décider d'une conception, /pstack:interrogate pour chercher les failles ; des IA d'appoint quand il y a beaucoup à faire.

vérifier

Il vérifie avant de rendre la main

Vraie sortie des commandes, captures d'écran, avant/après. Si quelque chose ne peut pas être vérifié, il le dit.
