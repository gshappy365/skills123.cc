처음 써 보기

한 줄 요약세 부분으로 된 메시지 하나를 보내서, 마신 물을 기록하는 작은 페이지를 만들어요.

이번 레슨에서는 pstack으로 작지만 진짜로 쓸 수 있는 걸 만들어요. 매일 물을 몇 잔 마셨는지 기록하는 웹페이지예요. 다 하고 나면 평소의 AI와 뭐가 다른지 알게 돼요.

먼저, 빈 폴더 만들기

  1. 바탕화면에 water라는 이름으로 새 폴더를 만드세요.
  2. Claude Code가 열려 있다면 /exit를 입력해서 종료하세요.
  3. 같은 창에서 이 한 줄을 입력하고 Enter를 누르세요. “바탕화면의 water 폴더로 들어가기”라는 뜻이에요.
  1. claude를 입력하고 Enter를 누르세요. 그 폴더 안에서 Claude Code가 열려요.

새 폴더를 만드는 이유: AI는 Claude Code를 연 폴더 안에서 일해요. 새로 만든 빈 폴더라면, 컴퓨터의 다른 것은 건드릴 수 없어요.

이 메시지를 보내세요

복사해서 입력창에 붙여 넣고 Enter
/pstack:poteto-mode 매일 마신 물의 양을 기록하는 작은 웹페이지를 만들어 주세요. 여기는 빈 폴더예요. 필요한 준비는 알아서 해 주세요.
완성된 모습: 페이지를 열고 “한 잔 마셨어요”를 누르면 오늘 잔 수가 하나 늘어나요. 닫았다가 다시 열어도 숫자가 그대로 있어요. 페이지에서 최근 7일 동안 매일 몇 잔 마셨는지 볼 수 있어요.
끝나면 보여 줄 것: 어떻게 확인했는지, 뭘 해 봤고 뭐가 보였는지. 가능하면 스크린샷도. 마지막으로 페이지를 여는 방법을 알려 주세요.

맨 앞의 /pstack:poteto-mode는 스위치예요. 이걸 붙이면 AI가 pstack의 규칙대로 일해요. 안 붙이면 평소처럼 일해요.

나머지 메시지는 딱 세 부분이에요. 이게 pstack을 쓰는 요령의 전부예요.

원하는 것 · 완성된 모습 · 끝나면 보여 줄 것
  • 원하는 것: 물을 기록하는 페이지.
  • 완성된 모습: 누르면 하나 늘어나고, 닫았다 다시 열어도 숫자가 남아 있고, 7일 치가 보여요. 이건 “어떻게 되면 끝인지”를 알려 주는 거예요. AI는 이걸 하나하나 확인해요.
  • 끝나면 보여 줄 것: 어떻게 확인했고 뭘 알아냈는지. 코드는 읽을 수 없으니, 당신이 이해할 수 있는 걸 보여 달라고 하세요.

중간에 멈추고 물어볼 거예요

몇 분 정도 작업해요. 그동안 Claude Code가 멈추고 물어봐요. 이 파일을 만들어도 될까요? 이 명령어를 실행해도 될까요?

이건 Claude Code가 당신을 지키는 방법이에요. 모든 단계에 당신의 허락이 필요해요. 이 폴더는 새로 만든 빈 폴더니까 Yes(예)를 고르세요.

답장에서 어디를 볼까

답장은 평소보다 길고, 전문 용어가 가득할 수도 있어요. 모르는 부분은 건너뛰고, 표시된 네 곳만 보세요.

  • 먼저 ①을 보세요. 제대로 이해했나요? 아니라면 “7일 말고 30일”처럼 그냥 입력해서 고쳐 주세요.
  • ②는 AI가 하려는 단계예요. 진행하면서 하나씩 체크해요. 당신이 관리할 필요는 없어요.
  • ③이 가장 중요해요. 줄마다 뭘 했고 뭘 봤는지 쓰여 있어요. “확인 못 한 것” 줄은 AI가 솔직하게 말하는 거고, 좋은 신호예요.
  • ④에 쓰인 대로 해서 직접 확인해 보세요.

잘했는지 알아보는 법

스스로에게 세 가지를 물어보세요.

  • AI가 다시 말한 목표가 내가 생각한 것과 같은가요?
  • 다 됐다고 할 때, 실제로 해 본 확인과 그때 본 것을 나열했나요?
  • 내가 직접 열어 봤을 때, AI가 말한 대로인가요?

세 개 모두 “네”라면 일이 끝난 거예요.

확인한 내용 없이 “다 됐어요”라고만 했다면, 아직 안 끝난 거예요. 이렇게 답하세요.

이걸 복사하세요
실제로 확인한 결과를 보여 주세요. 무엇을 해 봤고, 무엇이 보였는지 알려 주세요. “다 됐어요”라고만 하지 말고요.

틀렸을 때 뭐라고 할까

결과가 틀렸어요. 예를 들어 눌러도 숫자가 안 바뀌어요.

본 것만 말하세요. 예를 들면 “세 번 눌렀는데 숫자가 계속 0이에요.” 원인은 추측하지 않아도 돼요. 추측이 틀리면 AI가 엉뚱한 방향으로 가요.

답장이 길고 모르는 말투성이예요.

/pstack:bro를 입력하세요. 바로 앞의 답장을 쉬운 말로, 훨씬 짧게 다시 말해 줘요.

이해가 안 되는 질문을 받았어요.

이렇게 답하세요. “저는 코딩을 몰라요. 쉬운 말로 물어봐 주세요. 아니면 가장 안전한 쪽을 대신 골라 주고, 왜 그걸 골랐는지 알려 주세요.”

부탁하지 않은 걸 하고 있어서 멈추고 싶어요.

Esc를 누르면 멈춰요. 그다음 원하는 걸 말하세요. 예를 들면 “물 기록만 해 주세요. 다른 건 나중에 생각할게요.”

Windows에서 cd 줄을 입력하면 폴더를 찾을 수 없다고 나와요.

어떤 Windows 컴퓨터는 바탕화면이 OneDrive 안에 있어요. 대신 cd ~/OneDrive/Desktop/water를 입력해 보세요.

Claude 데스크톱 앱을 쓰는데, cd를 입력할 곳이 없어요.

새 세션을 시작할 때 폴더를 고르라고 나와요. 바탕화면의 water를 고르세요. 나머지는 똑같아요.

이제 쓸 수 있어요

앞으로 무슨 일을 하든 모양은 똑같아요. /pstack:poteto-mode에 세 부분을 붙이면 돼요. 예시를 두 개 더 볼게요.

자꾸 다시 생기는 문제 고치기
/pstack:poteto-mode 내 북마크 확장 프로그램에서 저장을 누르면 가끔 같은 항목이 두 번 저장돼요.
완성된 모습: 저장을 열 번 연달아 눌러도 목록에는 하나만 있어요.
끝나면 보여 줄 것: 문제를 어떻게 다시 일으켰는지, 그리고 고친 다음 다시 해 봤을 때 어떻게 됐는지.
아무것도 바꾸지 말고, 이해만 하고 싶을 때
/pstack:how 이 폴더 안의 것들은 어떻게 작동하나요? 저는 코딩을 모르니까 쉬운 말로 설명해 주세요.

두 번째 예시는 /pstack:how를 써요. 설명만 하고, 당신의 파일은 건드리지 않아요. 바꿀지 말지 정하기 전에 먼저 이해하고 싶을 때 쓰세요.

지금은 여기까지면 충분해요

처음 시작하는 분께 필요한 건 이 세 레슨이 전부예요. 여기서부터 가장 좋은 연습은, 진짜로 만들고 싶은 작은 걸 하나 골라서 똑같은 세 부분으로 말해 보는 거예요.

사이트의 나머지 내용은 필요할 때 찾아보세요(모두 영어예요).

  • AI가 엉뚱한 쪽으로 가요: Pull it back on track(다시 제자리로 돌리기)
  • 요금제 사용량이 금방 줄어요: Keep costs down(비용 줄이기)
  • 다른 궁금한 점: FAQ(자주 묻는 질문)
  • 코딩을 하고, 더 큰 프로젝트에 쓰고 싶어요: 전체 가이드
