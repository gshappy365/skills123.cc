AI가 “다 됐어요”라고 하기 전에, 직접 해 보게 하세요

pstack은 AI에 설치해서 쓰는 무료 오픈소스 “일하는 규칙”이에요. 설치하면 AI가 먼저 당신이 원하는 게 뭔지 확인하고, 바꿔야 할 곳만 바꿔요. 코딩을 몰라도 괜찮아요.

처음이라면 여기서 시작코딩하는 분: 전체 가이드 (영어)

입문 코스는 레슨 3개, 20분이에요.

이런 일, 겪어 본 적 있나요?

  • AI가 “다 됐어요!”라고 해요. 열어 보면 버튼을 눌러도 아무 반응이 없어요.
  • “아직 안 돼요”라고 하면 “죄송해요, 고쳤어요”라고 해요. 그런데 결과는 똑같아요. 그게 계속 반복돼요.
  • 작은 것 하나만 바꿔 달라고 했는데, 부탁하지도 않은 곳을 잔뜩 바꿔 놨어요.

설치하면 뭐가 달라질까요

언제평소의 AIpstack을 쓴 AI
시작하기 전원하는 게 뭔지 확인 없이 바로 시작먼저 당신의 목표를 자기 말로 다시 말해서, 틀리면 바로 고칠 수 있어요
고치는 동안그럴듯해 보이는 곳을 일단 바꿈먼저 문제를 찾아낸 다음, 최대한 적게 바꿔요
“다 됐어요”라고 할 때“이제 괜찮을 거예요”실제로 뭘 확인했고 뭘 봤는지 나열하고, 확인 못 한 건 솔직하게 말해요

처음이라면 레슨 3개면 돼요

순서대로 읽으면 다 합쳐 20분. 이 세 개만 끝내면 쓸 수 있어요. 사이트의 나머지 내용은 나중에 필요할 때 찾아보는 용도예요.

  1. 1무엇을 해 주나요3분 · pstack이 뭔지, 뭐가 필요한지, 대신 뭘 감수해야 하는지
  2. 2설치하기5분 · Claude Code에 두 줄 입력하고 하나만 고르면 끝
  3. 3처음 써 보기10분 · 세 부분으로 된 메시지 하나로 작은 웹페이지 만들기

나한테 맞을까요?

이런 분께 맞아요

  • AI로 작은 페이지나 확장 프로그램, 도구를 만들어 봤고, “다 됐어요”인데 안 돼서 고생한 적이 있는 분
  • Claude Code(또는 Cursor, Codex)가 이미 있고, 그 안에서 AI와 대화할 수 있는 분
  • 빠른 것보다 제대로 되는 게 더 중요한 분

아직은 이른 분

  • Claude Code 같은 도구를 아직 안 써 본 분: 먼저 공식 가이드대로 설치하고, 대화할 수 있게 되면 다시 오세요
  • 오타나 색 바꾸기 같은 아주 작은 수정: AI에게 그냥 바로 말하면 돼요
  • 무조건 빠르고 싸게만 하고 싶은 분: pstack은 확인을 더 많이 해서 느리고, 요금제 사용량도 더 많이 써요

코딩하는 분이라면

pstack은 poteto(React 코어 팀 멤버, Cursor 근무)가 매일 자기 코드에 쓰는 스킬 모음이에요. 스킬 34개, 플레이북 23개, 엔지니어링 원칙 24개. 아래는 모든 작업에서 거치는 4단계와, 9단계짜리 전체 가이드예요.

전체 가이드는 지금은 영어(와 중국어)로만 있어요.
