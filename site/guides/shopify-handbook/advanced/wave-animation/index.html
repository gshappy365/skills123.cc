一分钟了解水波浪动画

原创开发了Shopify 主题很火的水波浪动画（Wave Animation）增强组件，让您的商店瞬间拥有专业级的动态效果！ 已兼容移动端，适配绝大部分主题，支持灵活控制波浪颜色、速度、高度、动画速度、背景颜色、透明度、波浪样式、显示标题&描述。

✨ 效果展示

1. 柔和的波浪在页面底部轻柔流动
2. 完全可自定义颜色和速度
3. 完美适配所有设备
4. 不影响网站加载速度

三步安装，立即使用

第1步：获取代码（30秒）

第2步：上传到主题（1分钟）

  1. Shopify后台 → 在线商店 → 主题
  2. 点击 操作 → 编辑代码
  3. 在 sections 文件夹中 → 添加新 section
  4. 命名为 wave-animation，粘贴代码，保存

第3步：添加到页面（1分钟）

  1. 进入主题编辑器
  2. 选择要添加动画的页面
  3. 点击 添加分区 → 选择 水波浪动画
  4. 预览效果，完成！
