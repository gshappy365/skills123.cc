什么是产品系列？

产品系列是将相关产品分组的方式，可以基于：

  • 产品类型（如服装、配饰、家居用品）
  • 目标受众（如男士、女士、儿童）
  • 价格区间（如特价商品、高端商品）
  • 季节或主题（如夏季系列、节日礼品）
  • 特定特征（如颜色、材质、风格）

系列的类型

Shopify提供两种类型的系列：

1. 手动产品系列

手动产品系列需要你逐个选择要添加的产品。

优点：

  • 完全控制哪些产品出现在系列中
  • 适合小型精选系列或特色商品展示

缺点：

  • 随着产品数量增加，管理可能变得繁琐
  • 需要手动更新

2. 自动产品系列

自动产品系列基于你设置的条件（如标签、产品类型、价格等）自动包含符合条件的产品。

优点：

  • 一旦设置完成，会自动维护
  • 当添加新产品时，如符合条件会自动添加到相应系列
  • 适合大型商店和频繁更新库存的情况

缺点：

  • 需要保持一致的产品标记和分类方式
  • 可能需要定期检查确保逻辑正确

创建手动系列

按照以下步骤创建手动系列：

  1. 在Shopify管理后台，点击产品，选择[产品系列]（https://admin.shopify.com/collections%EF%BC%89 
  2. 点击创建系列按钮
  3. 输入系列标题（如夏季新品）
  4. 添加描述，这将显示在系列页面上，有助于SEO
  5. 上传系列图片，作为系列的视觉代表
  6. 在系列类型部分，选择手动
  7. 保存系列
  8. 在产品选项卡中，搜索并选择要添加到系列的产品
  9. 点击添加将选定的产品加入系列

创建自动产品系列（以前叫做自动，现在叫做智能产品系列）

创建自动产品系列的步骤：

  1. 在Shopify管理后台，点击产品，选择[产品系列]（https://admin.shopify.com/collections%EF%BC%89 
  2. 点击创建产品系列按钮
  3. 输入产品系列标题（如低于¥100的商品）
  4. 添加描述和上传系列图片
  5. 在产品系列类型部分，选择自动
  6. 设置条件：
    • 选择条件类型（如产品标签、产品类型、价格等）
    • 选择运算符（如等于、大于、包含等）
    • 输入包含值（如夏季、100等）
  7. 可以添加多个条件，并选择满足所有条件或满足任一条件
  8. 点击顶部保存按钮，保存产品系列

最多可以添加 60 个选择条件，指定产品是需要满足所有条件还是任意条件即可包含在产品系列中。

Shopify产品系列优化策略

命名和描述

  • 使用清晰、简洁的系列名称
  • 在描述中包含相关关键词，帮助搜索引擎优化
  • 描述应突出系列的独特价值和适用场景

系列图片

  • 选择能代表整个系列的高质量图片
  • 保持图片风格统一，与店铺整体设计协调
  • 考虑为季节性或促销系列创建专属的图片

系列排序

控制产品在系列中的显示顺序：

  1. 编辑系列
  2. 在排序部分，选择以下排序方式之一：
    • 手动（仅适用于手动系列）
    • 畅销商品优先
    • 价格从低到高
    • 价格从高到低
    • 标题按字母顺序
    • 创建日期（最新优先）
    • 创建日期（最旧优先）

对于手动系列，你还可以通过拖放来调整产品顺序。

在店铺中展示系列

导航菜单

将重要系列添加到导航菜单：

  1. 在Shopify管理后台，前往在线商店 > 导航
  2. 编辑主菜单
  3. 点击添加菜单项
  4. 选择系列
  5. 保存菜单

主页展示

在主页上展示特定系列：

  1. 前往在线商店 > 主题
  2. 点击自定义
  3. 添加精选系列区块
  4. 选择要展示的系列
  5. 保存更改

使用系列页面模板

大多数Shopify主题提供多种系列页面模板，允许你自定义系列的显示方式：

  1. 编辑系列
  2. 在模板部分，选择合适的模板（视主题而定）
  3. 预览不同模板的效果
  4. 选择最适合该系列的模板样式

高级系列策略

子系列结构

创建层次化的系列结构，如服装作为主系列，下设男装、女装和童装子系列：

  1. 创建所有需要的系列
  2. 在导航设置中，创建下拉菜单结构
  3. 添加主系列作为菜单项
  4. 在其下添加子菜单项，链接到相应的子系列

限时系列

为促销或季节性商品创建限时系列：

  1. 创建自动系列，使用标签作为条件
  2. 为促销商品添加特定标签（如冬季促销2023）
  3. 促销结束后，只需删除标签即可从系列中移除产品
  4. 或选择在特定日期后隐藏整个系列

交叉销售系列

创建相关产品或搭配推荐系列，提高客单价：

  1. 为互补产品创建手动系列
  2. 在产品页面模板中添加相关产品部分
  3. 配置该部分显示特定的交叉销售系列
