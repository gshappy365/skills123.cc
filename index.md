# Skills123.cc

AI Agent Skills 百科 -- 深度介绍、使用指南与案例分析

Skills123.cc 是一个专注于 **AI Agent Skills** 的中文百科站点。我们系统化地收录、解读和分析来自 **Anthropic knowledge-work-plugins** 和 **OpenAI Codex** 两大生态的官方技能与社区精选，帮助开发者、分析师、营销人员、法务、财务等各行业从业者快速找到适合自己的 AI 技能，并真正用起来。
