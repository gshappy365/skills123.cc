# 什么是 Codex

Codex 是 OpenAI 推出的 AI 编程与办公代理。最初定位为编码助手，经过持续迭代，Codex 已演变为覆盖编程、数据分析、创意制作、销售、金融等多个领域的 AI 工作平台。

## 快速增长

截至 2026 年中，Codex 周活跃用户突破 **500 万**，自 2025 年桌面版上线以来增长 6 倍。关键的结构性变化是：非开发者用户（分析师、营销、运营、设计师、投资人）已占 20%，增速是开发者的 3 倍以上。

| 指标 | 数据 |
|---|---|
| 周活跃用户 | 500 万+ |
| 桌面版上线后增长 | 6 倍 |
| 非开发者占比 | 20%（增速为开发者 3 倍） |
| 数据分析任务增长 | 周环比 110% |

## 角色专属插件

2026 年 5 月，Codex 发布了六个角色专属插件，标志着从"编程工具"到"办公平台"的转型：

| 插件 | 目标用户 | 核心能力 |
|---|---|---|
| 数据分析 | 分析师 | 连接 Snowflake、Tableau，一句话完成数据查询到图表生成 |
| 创意制作 | 营销、设计 | 打通 Figma、Canva，从创意简报直接生成广告素材 |
| 销售 | 销售代表 | 串联 Salesforce、HubSpot，完成客户研究和跟进 |
| 产品设计 | 产品经理 | 基于 Figma 将线框图变成可点击原型 |
| 公共股权投资 | 投资人 | 对接 FactSet、PitchBook，做盈利分析和投资逻辑验证 |
| 投行 | 投行分析师 | 将尽调材料转化为 Pitch 文档 |

## Sites 功能

Sites 是 Codex 最具想象力的功能之一。用户用自然语言描述需求，Codex 直接生成一个**可分享的交互式网页应用**，通过 URL 分享给团队成员。财务负责人可以把 Excel 模型变成在线场景规划器，产品经理可以生成项目 Hub 页面。这直接威胁 Tableau、Power BI 等 BI 工具的中间层。

## 与 ChatGPT 的合并趋势

Codex 和 ChatGPT 在 OpenAI 内部已由同一团队管理。Tibo（Codex 负责人）的个人简介已写为"Codex & ChatGPT"。趋势是 Codex 将并入 ChatGPT——聊天只是入口，干活才是正事。

## 对 Skills123.cc 的意义

Codex 的插件生态与 Anthropic 的 knowledge-work-plugins 形成了互补。Codex 的优势在于办公场景（数据分析、销售、金融），Anthropic 的优势在于开发场景（工程、代码审查、系统设计）。Skills123.cc 同时覆盖两个生态，为用户提供跨平台的技能参考。
