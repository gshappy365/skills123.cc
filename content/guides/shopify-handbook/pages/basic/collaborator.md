若你聘请了建站、主题、应用或营销服务商，对方通常需要以 **合作者（Collaborator）** 身份进入你的店铺后台，而不是共用你的登录密码。合作者使用自己的 Shopify 合作伙伴账号登录，你通过 **4 位合作者代码** 发起邀请，并在「用户」里审批 **角色与权限**；对方**不计入店铺员工人数上限**，且**不能**被设为与店主等同的「店主」级管理员。

官方说明与界面变更以 Shopify 帮助中心为准：[合作者（Collaborator）](https://help.shopify.com/manual/your-account/staff-collaborators/collaborators) （英文文档，可在页内切换语言）。若你刚开店，可先读 [Shopify 入门指南](https://shopify.baoea.com/basic/getting-started) 与 [开始使用 Shopify](https://shopify.baoea.com/basic/shopify-registration)。

## 合作者与「员工」有什么区别（一句话）[](https://shopify.baoea.com/basic/collaborator#%E5%90%88%E4%BD%9C%E8%80%85%E4%B8%8E%E5%91%98%E5%B7%A5%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB%E4%B8%80%E5%8F%A5%E8%AF%9D)

*   **员工（Staff）**：占用店铺员工名额，一般由店主在后台直接创建账号或发邀请。
*   **合作者（Collaborator）**：由 **Shopify 合作伙伴计划** 中的账号发起访问请求，用你提供的 **合作者代码** 关联到你的店；适合外包、代理商、一次性项目。

下文默认你是 **店铺店主**，且后台菜单为 **设置 → 用户**（部分套餐或组织下菜单名称可能略有差异，以你当前后台为准）。

* * *

## 为什么要用合作者而不是把密码给对方[](https://shopify.baoea.com/basic/collaborator#%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E7%94%A8%E5%90%88%E4%BD%9C%E8%80%85%E8%80%8C%E4%B8%8D%E6%98%AF%E6%8A%8A%E5%AF%86%E7%A0%81%E7%BB%99%E5%AF%B9%E6%96%B9)

*   **最小权限**：按角色勾选「主题」「应用」「订单」等，项目结束可收紧或移除。
*   **审计更清晰**：谁在什么时间以合作者身份访问，与店主日常登录分离。
*   **降低泄露风险**：不必把店主账号交给第三方；代码与店铺 URL 也不要发在公开论坛。

合作者即你授权进入店铺后台、协助开发或运营的一方（常见为 Shopify 合作伙伴或服务商），通过合作者流程登录自己的专业账号完成工作。

**常见优势：**

*   合作者一般**不计入**店铺员工数量限制（以你套餐与 Shopify 当前政策为准）。
*   对方用**自己的**合作伙伴账号访问，无需与你共用密码。
*   你可为对方配置**自定义角色**或调整权限范围。

## 添加合作伙伴：店主端三步[](https://shopify.baoea.com/basic/collaborator#%E6%B7%BB%E5%8A%A0%E5%90%88%E4%BD%9C%E4%BC%99%E4%BC%B4%E5%BA%97%E4%B8%BB%E7%AB%AF%E4%B8%89%E6%AD%A5)

⚠️

通常仅 **店铺店主** 可在后台生成合作者代码并审批请求；若你只有员工子账号，需由店主操作或请店主授予相应管理权限。

### 第一步：获取合作者访问代码[](https://shopify.baoea.com/basic/collaborator#%E7%AC%AC%E4%B8%80%E6%AD%A5%E8%8E%B7%E5%8F%96%E5%90%88%E4%BD%9C%E8%80%85%E8%AE%BF%E9%97%AE%E4%BB%A3%E7%A0%81)

1.  登录 Shopify 后台，打开 **设置（Settings）** → **用户（Users）**（或「用户和权限」类入口）。
2.  打开 **安全性（Security）** 或与合作者相关的区域（菜单名称以你后台为准）。
3.  找到 **合作者请求代码（Collaborator request code）**，一般为 **4 位数字**，点击复制。
4.  将 **代码** 与 **店铺地址** 发给对方。店铺地址指你后台顶部或设置中显示的店铺链接（常见为 `xxx.myshopify.com` 形式），便于对方在合作伙伴面板里选对店铺。

![Shopify 后台设置中复制合作者请求代码的位置示意](https://shopify.baoea.com/_next/image?url=%2Fimages%2Fcontents%2Fset-collaborator.png&w=1200&q=75)

**安全建议：** 只通过私信、工单或加密渠道发送代码；代码相当于「允许对方发起进门申请」的钥匙，不要在群聊、评论区公开张贴。

### 第二步：合作伙伴发起访问请求[](https://shopify.baoea.com/basic/collaborator#%E7%AC%AC%E4%BA%8C%E6%AD%A5%E5%90%88%E4%BD%9C%E4%BC%99%E4%BC%B4%E5%8F%91%E8%B5%B7%E8%AE%BF%E9%97%AE%E8%AF%B7%E6%B1%82)

对方在其 **Shopify 合作伙伴（Partner）** 后台中：

1.  使用合作伙伴账号登录。
2.  选择「请求访问商店」或同类入口，填写你的 **店铺域名 / URL** 与 **4 位代码**。
3.  勾选其工作所需的 **权限**（如主题、应用、订单只读等）。

权限应与其交付物一致；若对方申请的权限明显超出范围（例如只做主题却勾选全部财务权限），建议先沟通再批准。

### 第三步：你在后台审批请求[](https://shopify.baoea.com/basic/collaborator#%E7%AC%AC%E4%B8%89%E6%AD%A5%E4%BD%A0%E5%9C%A8%E5%90%8E%E5%8F%B0%E5%AE%A1%E6%89%B9%E8%AF%B7%E6%B1%82)

你会收到 **邮件** 与后台 **通知**（具体以 Shopify 当前行为为准）：

1.  进入 **设置 → 用户**。
2.  在用户列表中筛选 **待处理 / 请求（Requests）** 或类似状态。
3.  打开对应合作者请求，查看对方申请的权限说明。
4.  在 **角色（Roles）** 中可：使用自动生成的角色并微调、分配已有角色，或新建专用角色。
5.  确认无误后点击 **接受**；若不合作则 **拒绝**。

拒绝后若需再次合作，通常需对方重新发起请求；具体可让对方咨询 [Shopify 合作伙伴支持](https://help.shopify.com/partners) 。

## 权限与收尾：避免「做完项目仍开着大门」[](https://shopify.baoea.com/basic/collaborator#%E6%9D%83%E9%99%90%E4%B8%8E%E6%94%B6%E5%B0%BE%E9%81%BF%E5%85%8D%E5%81%9A%E5%AE%8C%E9%A1%B9%E7%9B%AE%E4%BB%8D%E5%BC%80%E7%9D%80%E5%A4%A7%E9%97%A8)

### 授予权限的原则[](https://shopify.baoea.com/basic/collaborator#%E6%8E%88%E4%BA%88%E6%9D%83%E9%99%90%E7%9A%84%E5%8E%9F%E5%88%99)

*   **默认最小**：仅开放完成任务所需的模块（例如仅主题与在线商店，不必默认开放客户 PII 导出类能力，除非业务必需）。
*   **用角色固化习惯**：为长期合作的团队建「主题开发」「广告投放」等角色，便于复用与审计。
*   合作者**不能**等同于店主；敏感操作仍应由店主或核心员工执行。

### 项目结束后删除合作者[](https://shopify.baoea.com/basic/collaborator#%E9%A1%B9%E7%9B%AE%E7%BB%93%E6%9D%9F%E5%90%8E%E5%88%A0%E9%99%A4%E5%90%88%E4%BD%9C%E8%80%85)

1.  **设置 → 用户**。
2.  点击该合作者条目。
3.  选择 **删除合作者账户 / Remove collaborator**（文案以你后台为准）。
4.  按提示输入密码确认。

若仅短期暂停合作，也可先 **收紧权限** 而非立刻删除，便于同一团队后续继续维护。

## 常见问题[](https://shopify.baoea.com/basic/collaborator#%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)

### 我应该授予哪些权限？[](https://shopify.baoea.com/basic/collaborator#%E6%88%91%E5%BA%94%E8%AF%A5%E6%8E%88%E4%BA%88%E5%93%AA%E4%BA%9B%E6%9D%83%E9%99%90)

只授予对方说明里与交付物直接相关的权限。若对方申请「全选」，请其逐项解释用途；无法解释的一律先不勾选。

### 能否限制对方只能动某些应用或渠道？[](https://shopify.baoea.com/basic/collaborator#%E8%83%BD%E5%90%A6%E9%99%90%E5%88%B6%E5%AF%B9%E6%96%B9%E5%8F%AA%E8%83%BD%E5%8A%A8%E6%9F%90%E4%BA%9B%E5%BA%94%E7%94%A8%E6%88%96%E6%B8%A0%E9%81%93)

在审批请求时，Shopify 通常允许按 **应用、销售渠道** 等维度收紧（以审批页选项为准）。主题开发常见组合为：在线商店 / 主题 / 指定应用。

### 对方能用手机 App 进我的店吗？[](https://shopify.baoea.com/basic/collaborator#%E5%AF%B9%E6%96%B9%E8%83%BD%E7%94%A8%E6%89%8B%E6%9C%BA-app-%E8%BF%9B%E6%88%91%E7%9A%84%E5%BA%97%E5%90%97)

合作伙伴常需先在 **合作伙伴控制面板** 中完成对你店铺的访问流程；之后是否可用某款 App 取决于其权限与 Shopify App 策略，以实际登录结果为准。

### 误点了拒绝怎么办？[](https://shopify.baoea.com/basic/collaborator#%E8%AF%AF%E7%82%B9%E4%BA%86%E6%8B%92%E7%BB%9D%E6%80%8E%E4%B9%88%E5%8A%9E)

请对方在合作伙伴侧 **重新发起访问请求**；若流程卡住，联系 [Shopify 合作伙伴支持](https://help.shopify.com/partners)  说明情况。

### 对服务质量有争议怎么办？[](https://shopify.baoea.com/basic/collaborator#%E5%AF%B9%E6%9C%8D%E5%8A%A1%E8%B4%A8%E9%87%8F%E6%9C%89%E4%BA%89%E8%AE%AE%E6%80%8E%E4%B9%88%E5%8A%9E)

若涉及合作伙伴计划行为问题，可通过 Shopify 官方渠道了解 **举报或纠纷** 相关表单与流程（以 [合作伙伴计划政策](https://www.shopify.com/partners/terms)  页面为准）。

## 小结[](https://shopify.baoea.com/basic/collaborator#%E5%B0%8F%E7%BB%93)

添加合作伙伴的核心是：**店主生成代码 → 对方用合作伙伴账号请求访问 → 你在「用户」里按角色批准**。把权限当作合同附件一样逐条核对，并在项目结束后 **删除或降级访问**，比单纯追求「收录」更能保护店铺长期安全。
