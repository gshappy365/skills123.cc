# How-to：一篇只讲一件事

## 一篇只讲一件事

每篇结构一样：什么时候用、一段能照抄的话、你会看到什么、不对怎么办。尖括号换成你自己的内容就能发。

## 四组

| 组 | 你在干什么 | 篇数 |
| --- | --- | --- |
| **A · 看懂一个应用** | 手上有一个具体目标，想搞清它怎么做的 | 6 |
| **B · 找东西** | 知道要找什么，但不知道在哪 | 4 |
| **C · 发布与自动化** | 为自己的产物做检查，或放进流水线 | 3 |
| **D · 排错与省钱** | 慢、贵、没证据、起不来 | 4 |
