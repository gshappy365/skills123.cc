# 引导（Guidance）

## 一句话

给模型看的说明书，不是给你看的菜单。

## 打个比方

菜谱。食材（工具）是一回事，先炒什么后放什么是另一回事。

## 在 REA 里

`guided_workflows` 列出已安装的工作流，`search_guidance` 搜，`read_guidance_section` 读。setup 装的那份技能文件就是它。

## 常见误区

以为不装技能也能一样好用。能用，但模型会更随性——顺序错了，结论就容易飘。
