# 账本（Ledger）

## 一句话

每条证据按编号存进去的一本账，属于**当前这个连接**。

## 打个比方

一次实验的记录本。换个实验室，本子不跟着走。

## 在 REA 里

新连接不共享旧记录；换目标不丢；`close_binary` 不删；`reset_investigation` 才清。要跨会话就得导出 bundle，下一轮用文件引用。

## 常见误区

以为它会把历史攒起来。不会——这是为了不让一次分析的噪声污染下一次。
