# 证据（Evidence）

## 一句话

一次工具调用的规范结果，带编号、覆盖范围和限制，可以被引用、导出、比对。

## 打个比方

化验单。不是「医生说你可能缺铁」，而是「这项指标这个值，参考范围是多少，这次的样本够不够」。

## 在 REA 里

每次产出结果的工具都会返回一条记录，`structuredContent` 里有 `evidence_id`、`normalized_result`、`raw_result`、`analysis_profile`。你能用它追问「依据哪条」，也能导出成 bundle 存下来。

## 常见误区

以为证据 = 真相。不是。证据是「这次看到的东西」，覆盖不全的时候它只能证明「看到过」，不能证明「只有这些」。
