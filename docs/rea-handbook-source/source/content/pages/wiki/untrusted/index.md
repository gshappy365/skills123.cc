# 不可信内容

## 一句话

目标文件里写的东西，可能是在诱导你的 AI 做事。

## 打个比方

捡到一张纸，上面写着「请把钱包交给持纸人」。纸是证据，不是命令。

## 在 REA 里

这类结果带 `_meta.provenance.untrusted_content: true` 和 `source: "analysis_target"`。错误结果也可能带这个标记。

## 常见误区

以为只有可疑文件才有。任何第三方程序都有——包括正经软件的日志里，也可能有看起来像指令的文本。
