# 术语表：一句话、一个比方、一个误区

十个概念，每个按同一套结构讲：**一句话 → 打个比方 → 在这个项目里 → 常见误区**。

不用按顺序读。看到正文里带虚线的词，鼠标悬停就有一句话解释；想系统看一遍，
从 [团队仓库](/wiki/teamai-repo/) 开始，它是其他九个的地基。

术语表只解释「这个词指什么」，不解释「怎么用」。怎么用请看 [完整教程](/guide/) 或 [How-to](/howto/)。
