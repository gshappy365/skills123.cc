# 新手入门：三课，20 分钟

不会写代码也能走完的三课，20 分钟。

1. [它能帮你什么](/start/1-why/)：四分钟判断值不值得做。
2. [装上它](/start/2-install/)：一句话让你的 AI 工具装好，或者自己 `npm install`。
3. [第一次接入](/start/3-join/)：加入团队，三个检查点确认资源真的到了。

每课都写了「你应该看到什么」，不对也有地方查。走完这三课，你就能和团队用同一套东西；
想管更多，再去 [完整教程](/guide/)。
