# Skills123 Redesign Decisions

## Package navigation

- Use prototype A, the grouped index.
- Group order is Development, Research, Operations, Content.
- Development and Research show active packages.
- Operations and Content retain their position and show coming-soon states.
- Global search covers packages and skills. A skill hit identifies its package and opens that package with the skill selected.

## Package workspace

- Every package uses one light Atlas workspace template.
- Desktop layout is filters, skill directory, and skill detail.
- Visual language is Skills123 warm paper, deep blue, muted gold, thin rules, and compact controls.
- Mobile layout is a top filter strip, skill directory, and bottom detail drawer.

## Long-form skills

- The detail panel contains summary, command, tags, and relationships.
- Long-form skills such as Serenity open a full-width reading view inside their package.
- Returning from reading restores the previous workspace state.
