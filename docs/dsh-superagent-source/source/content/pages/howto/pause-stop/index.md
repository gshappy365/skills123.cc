# 暂停、停止与解除

## 三个不同的动作

| 动作 | 作用范围 | 效果 |
| --- | --- | --- |
| `Pause processing` | 整个执行侧 | 暂停自动处理；面板里 Execution 页 |
| `Stop`（面板或一句「停一下」） | 单个工单 | 记作人工停止、**撤回 Mandate**，工单不再接收任何东西 |
| `Evaluate again` / `Retry` | 单条触发或工单 | 重新评估，或重试失败的输入 / 受阻的工单 |

## 人的暂停会一直保持

这是文档里特意强调的一条：**一个人下的暂停，会跨跟进消息、跨新的执行器会话、跨重启一直有效，直到人亲自解除；自动反馈不会把暂停的活重新唤醒。**所以别指望「过一会儿它自己就好了」。

`Stop` 更硬：它作用的是工单本身，会撤回那份不可变的授权。想继续，需要人明确地重新发起。

## 你应该看到什么

工单结局会写成 **Stopped by a person**，不是一串内部状态码。面板标签写的是「在等谁、等什么」。

## 不对怎么办

- 暂停后以为坏了：先看 Execution 页的 `Pause processing` 状态。
- 每小时自检任务把它重启了：自检提示词里会检查 `manually_stopped`，看到就保持停止；确认你的定时任务用的是带 `--respect-stop` 的版本。
