# 写 README 与说明文档

```
@<agent login> 把 README 里的安装与启动步骤更新成现在实际能跑通的版本。

要求：每一条命令都对照仓库当前脚本核对过；只改 README，不碰其他文件。
做完请给我：改了哪几行、以及你用来核对命令的依据。
```

## 为什么强调「只改文档」

这是练习「范围」最便宜的一次任务：文件少、容易审、出错也好还原。第一次用这套系统，拿它当第一个工单比改业务代码合适得多。

## 不对怎么办

它顺手改了配置让它「看起来更一致」——这在文档任务里很常见。回一句「只保留 README 的改动」。
