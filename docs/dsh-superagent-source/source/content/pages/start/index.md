# 新手入门：三课，20 分钟

## 不会写代码，也能顺着走完

三课，约 20 分钟，一条路走到底。每课都写了**你应该看到什么**，不对也有地方查。做完这三课，日常使用就够用了。

| 课 | 时间 | 你能做成什么 |
| --- | --- | --- |
| [1 · 它能帮你什么](/start/1-what/) | 3 分钟 | 判断值不值得学，知道要准备什么、付出什么 |
| [2 · 装上它](/start/2-setup/) | 5 分钟 | 用一句话让编码智能体带你装完 |
| [3 · 第一次派活](/start/3-first-task/) | 10 分钟 | 发一条三段式请求，看它交回一个 PR |

只想记一句话的话：**「我想要什么 · 做好是什么样子 · 做完给我看什么」**。

会写代码、要自己部署和维护？走 [完整教程九步](/guide/)。
