# 线程 Thread

## 一句话

==线程是按时间顺序排列的触发==，也是「同一时间只跑一个评估」的范围单位。

## 打个比方

像同一个话题的聊天记录。谁说了什么、按什么顺序说的，都在这条线上；讨论可以分出好几件待办，但阅读背景是同一份。

## 在这个项目里

- 由来源定义哪些触发算同一条线程；
- 同一条线程上最多同时跑一个[[评估|Eval]]，期间新到的触发合并进下一批；
- 一条线程可以挂**好几个**工单（设计里特意否决了「一条线程最多一个活的工单」）；
- 线程持有[[订阅|Subscription：工单与线程的多对多关系]]、正在跑的评估、以及决定历史；
- 「关联 Correlation」只表示几条线程共享过同一条触发：它**只加上下文，不负责路由**，路由是订阅的事。

## 常见误区

- 把线程当成一个 Issue 或一次对话：它是评估的一致性单元，不等同于任何外部对象。
- 以为「话题像」就能挂到已有工单：主会话只在消息明确指向某个工单的 PR / Issue / 原始消息，或恰好只匹配一个工单时才挂。
