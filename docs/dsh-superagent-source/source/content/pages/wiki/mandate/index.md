# 授权 Mandate

## 一句话

==授权是一次接单所授予的记录==：策略版本、范围、强度、命中的规则、发送者在该来源上的身份、来源是怎么收到这条触发的。

## 打个比方

像一张写明工作范围的派工单，盖了章就不能涂改。任务做完，这张单子还留着备查；要作废，得由人明确收回。

## 在这个项目里

- **不可变**：范围变大要另开工单，不能在原工单上放宽；
- 工单结束不会让它失效；只有人的 `stop` 撤回，或者已结束工单恢复前拿当前策略重新校验失败时被吊销；
- 策略变更不会取消正在跑的工单（避免半成品），而是把变更记录并送达它的派工；
- 它的存在把「授权」和「上下文」彻底分开：[[订阅|Subscription]]只送上下文，不带任何权限。

## 常见误区

- 当成登录凭证或权限位：它是一份**记录**，真正的权限由 host 和工具参数强制。
- 以为改提示词能放宽范围：不行，优先级里 host 强制的事实排在最前面。
