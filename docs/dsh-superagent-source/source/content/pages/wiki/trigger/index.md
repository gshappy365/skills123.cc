# 触发 Trigger

## 一句话

==触发是一条不可变事件==，带着来源给的元数据（例如是谁发的、是 @ 还是私信）。

## 打个比方

像收发室登记簿上的一行：写下来就不改，编号唯一。同一封信被送两次，登记簿上也只有一行。

## 在这个项目里

- 它属于一条或多条线程；同一条触发被接受两次，也只会生成一个[[工单|Ticket：一个被授权的工作单元]]；
- 是审计和**幂等**的单位——重启、重投、重复通知都不会让活干两遍；
- 每条触发都会留下去向记录（`Disposition`）：被过滤了、被评估了，还是被扇出了；
- 后续消息如果落到某个已订阅工单的线程，就直接作为上下文送给工单，**不再进评估**。

## 常见误区

- 以为触发可以编辑或「再消费一次」：它是不可变的。
- 以为评论里写几句话就能改权限：触发只是数据，权限由 host 与[[策略|Policy：版本化的接单规则与各来源的名单]]强制。
