### 学习路径说明

- **How do I get started?**：面向还没有写过代码的人，介绍 LLM 是什么、能做什么，以及为什么现在适合开始构建自己的软件。
- **How can I get AI to write code like me?**：面向已经会编程的人，重点是规则、上下文和工作流，让 Agent 的输出更符合个人标准。
- **How can I get the most out of AI coding?**：面向已经熟悉编码 Agent 的人，重点是计划校验、Tracer Bullets、上下文控制和架构质量。
