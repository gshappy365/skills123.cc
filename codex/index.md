# Codex 技能

OpenAI Codex 官方插件与社区高星技能的介绍与使用指南。

## 官方插件

Codex 内置的 12 个官方插件，由 OpenAI 官方维护：

| 插件 | 核心能力 |
|---|---|
| [GitHub](/codex/official/github) | 审查变更、管理 Issue、与仓库交互 |
| [Figma](/codex/official/figma) | 检查设计、提取规格、记录组件 |
| [Slack](/codex/official/slack) | 发送消息、搜索频道、管理对话 |
| [Notion](/codex/official/notion) | 创建和编辑页面、数据库和内容 |
| [Linear](/codex/official/linear) | 创建和管理 Issue、项目和流程 |
| Gmail | 阅读、搜索和撰写邮件 |
| Google Drive | 编辑和管理 Google Drive 文件 |
| Vercel | 部署、预览和管理 Vercel 项目 |
| Sentry | 监控错误、分类 Issue、跟踪性能 |
| Cloudflare | 管理 Workers、Pages、DNS 和基础设施 |
| Hugging Face | 浏览模型、数据集和 Spaces |
| Box | 访问和管理文件 |
